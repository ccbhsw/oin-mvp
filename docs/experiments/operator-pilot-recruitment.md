# 最小独立 Operator 试点：招募说明与资格问卷

## 使用边界

本文是**待人工批准的招募材料草案**，并不代表 OIN 已经拥有、联系或接纳任何真实 Operator。未经项目负责人明确批准，不得将其发布、发送给机构、收集联系信息或把回答写入公开仓库。

> OIN 试点寻求的不是“节点数量”，而是两个拥有不同管理、托管和退出路径的参与者，验证在明确授权范围内保存、复制、恢复和独立验证信息的实际成本与价值。

## 候选参与者说明

OIN 是一个签名、冲突保留、可离线验证的信息保存原型。它不会裁决内容是否为真，也不是区块链、代币、挖矿或投资项目。试点仅处理参与者明确拥有或获许可保存与复制的**公开样本**；不应上传个人敏感信息、未授权材料、秘密、生产凭据或受限访问内容。

参与者将在约 30 天内自主运行一个节点或受控节点环境，公开其选择公开的短期签名描述符，并与另一参与者**显式**交换 Bootstrap Bundle。复制并不会自动发生，任何复制行为都需要双方管理员明确执行。试点结束时，一方将模拟退出，另一方验证并导出历史证据，以检验恢复与可携带性。

| OIN 提供的价值假设 | 试点需要验证的事实 | 不作出的承诺 |
| --- | --- | --- |
| 机构可独立保留已授权资料的可验证历史 | 参与者是否认为本机构的保存、研究、公共使命或服务需求值得承担成本 | 不保证永久保存、法定合规、事实真实性或任何收益。 |
| 多个独立副本可降低单节点退出风险 | 两方在不同托管与管理条件下是否能恢复并离线验证样本 | 不声称两方即代表跨法域、跨资金或全球独立性。 |
| 开放格式与离线验证可降低锁定 | 退出时是否可以导出、验证并由对方保留历史 | 不替代正式 SLA、法律保留或版权许可。 |

## 最低资格与排除条件

| 项目 | 合格的最低说明 | 不适合本轮试点的情况 |
| --- | --- | --- |
| 组织或维护责任 | 指定一名负责配置、故障和退出演练的维护人。 | 无负责人，或希望由 OIN 无偿代运维。 |
| 保存动机 | 能说明本机构资料、研究、档案使命、连续访问或专业服务的收益。 | 主要期待代币、投机回报或“免费存储所有内容”。 |
| 独立性 | 披露与另一候选方在管理员、云账户、域名、资金、法域和机房方面的重叠。 | 两方使用同一私钥、同一管理员或同一云账户并声称独立。 |
| 样本授权 | 使用明确公开、已获得保存/复制许可的小型样本。 | 个人资料、登录内容、未授权抓取、非法或未审查的敏感内容。 |
| 成本记录 | 愿意以聚合数据记录存储、流量、工时、异常与恢复成本。 | 无法记录任何成本或维护投入。 |
| 网络暴露 | 将开发 API 留在受控网络或加访问控制。 | 直接暴露无认证开发 API 至公网。 |

## 资格问卷

候选方只需提供完成试点评估所必需的**最少信息**。不得收集私钥、口令、内部网络地址、个人身份号码、商业秘密或未获许可的样本内容。

| 编号 | 问题 | 预期回答形式 | 用途 |
| --- | --- | --- | --- |
| Q1 | 你希望保存或验证哪类已授权公开资料？为什么这对你的机构有价值？ | 一段非敏感文字 | 核验非投机性参与动机。 |
| Q2 | 谁负责 30 天内的配置、故障和退出演练？ | 角色名称或组织邮箱别名 | 评估维护责任，不公开个人信息。 |
| Q3 | 节点计划部署在自有硬件、机构云、商业云还是托管服务？ | 类别和地区级别 | 识别共同失败域。 |
| Q4 | 与另一候选方是否共享管理员、云账户、域名、资金来源、机房或法律实体？ | 是/否加简短说明 | 评估独立性，不作为信任评分。 |
| Q5 | 每周可记录哪些聚合指标？ | 勾选存储、流量、工时、故障、恢复、成本 | 确认可证伪的经济实验。 |
| Q6 | 退出时是否可导出并允许另一方保留已授权样本的可验证副本？ | 是/否及条件 | 评估迁移与恢复边界。 |
| Q7 | 是否存在隐私、版权、合同、法域或内部审查限制？ | 仅说明类别 | 决定是否应排除或缩小样本范围。 |
| Q8 | 30 天后继续、暂停或退出的判定条件是什么？ | 条件清单 | 防止把一次演示误写成长期承诺。 |

## 评估与公开原则

项目方应将回答仅用于试点准入和风险记录，不将其转换为“可信排名”。若接纳参与者，公开材料只能包含其书面同意发布的 Descriptor、试点范围、聚合测量结果和验证输出。任何发现的共同失败域、成本不可测、退出失败或授权不清晰都应如实标记为 **PARTIAL PASS** 或 **FAILED ASSUMPTION**。

试点不处理身份锚定变更、密钥轮换、物理删除、法律保留或标准治理投票。它们分别受项目红灯决策和独立法律/治理审查约束。
